# thai-postcodes.json

ตาราง รหัสไปรษณีย์ → [ตำบล/แขวง, อำเภอ/เขต, จังหวัด] ใช้ช่วยกรอกที่อยู่จัดส่งบนหน้าเว็บ

- 7,423 ตำบล/แขวง · 956 รหัสไปรษณีย์
- แปลงมาจาก npm `thai-address-database` (Sellsuki, สัญญาอนุญาต ISC) ซึ่งอ้างอิงข้อมูลของกรมการปกครอง
- อ่านฝั่ง server เท่านั้น (ผ่าน `/api/shop/postcode`) ไม่ได้ส่งทั้งไฟล์ไปให้ browser
