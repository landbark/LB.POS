# ไฟล์สินค้า (product-files)

ที่ทิ้งไฟล์ข้อมูลสินค้าให้ Claude อ่าน — ใบราคาจากตัวแทน, แคตตาล็อก, ไฟล์ export สินค้า,
รูปถ่ายใบราคา, ใบสั่งของ ฯลฯ

## วิธีใช้
1. ลากไฟล์มาวางในโฟลเดอร์นี้ (โฟลเดอร์เดียว ไม่ต้องแยกยี่ห้อ)
2. บอก Claude ว่า "ดูไฟล์ใน product-files/" แล้วบอกว่าจะให้ทำอะไร

## ตั้งชื่อไฟล์แบบนี้ช่วยได้มาก
`<ยี่ห้อหรือตัวแทน>-<เรื่อง>-<เดือนปี>.xlsx`

ตัวอย่าง:
- `whiskas-ใบราคา-A&A-พย2026.pdf`
- `petprotect-ใบสั่งของ-พย2026.md`
- `royalcanin-แคตตาล็อก-2026.xlsx`

ชื่อไฟล์เดือน/ปีสำคัญกว่าการแยกโฟลเดอร์ เพราะใบราคาเก่า-ใหม่หน้าตาเหมือนกัน
ถ้าไม่ระบุวัน Claude แยกไม่ออกว่าอันไหนใช้ล่าสุด

## ถ้าไฟล์เยอะขึ้นค่อยแยกโฟลเดอร์ย่อย
พอเกิน ~30 ไฟล์ค่อยแยกเป็น `product-files/<ตัวแทน>/` ทีหลังได้ ไม่ต้องแยกตั้งแต่ต้น

## รูปแบบไฟล์ที่อ่านได้
xlsx / xls / csv / pdf / md / txt / json / รูป (png, jpg, webp) — รูปถ่ายใบราคาด้วยมือถือก็อ่านได้

## ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น git
ตั้ง .gitignore ไว้แล้ว (ยกเว้นไฟล์ README นี้) — ใบราคามีราคาทุนกับเงื่อนไขตัวแทน
ไม่ควรขึ้น repo และไฟล์ xlsx/pdf ทำให้ repo บวม
